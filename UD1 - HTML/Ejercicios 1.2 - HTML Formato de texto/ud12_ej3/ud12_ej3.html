Ficha técnica: Visual Studio Code

Visual Studio Code es un editor de código fuente desarrollado por Microsoft. Permite escribir código de diferentes lenguajes de programación y facilita el desarrollo de aplicaciones.

Características

VSCode es compatible con numerosos lenguajes y permite instalar extensiones para añadir funcionalidades. Un IDE es un entorno de desarrollo integrado que reúne herramientas para programar.

HTML es uno de los lenguajes que podemos utilizar dentro de VSCode.

Ejemplo de código

Podemos escribir código HTML como el siguiente:

<h1>Hola mundo</h1>

Atajos de teclado

Para guardar un archivo podemos utilizar Ctrl + S.

Fecha de lanzamiento

Visual Studio Code fue lanzado el 29 de abril de 2015.

Versiones

Visual Studio Code recibe actualizaciones frecuentes. Podemos representar una versión como VSCode 1ª o utilizar subíndices en fórmulas como H2O.
