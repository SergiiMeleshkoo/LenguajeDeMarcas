
# UD24 - Ejercicio 2: Position

- **Static:** no se mueve porque ignora top, left, right y bottom.
- **Relative:** se desplaza respecto a su posición original, pero conserva su espacio.
- **Absolute:** sale del flujo normal. Con el contenedor en relative, se coloca respecto a él.
- **Z-index:** permite decidir qué elemento aparece por encima. He puesto el cuadro 1 por encima del 2.
