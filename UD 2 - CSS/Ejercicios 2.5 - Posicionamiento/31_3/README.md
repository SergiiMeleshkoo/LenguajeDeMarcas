
# UD24 - Ejercicio 4

## Parte A
La tarjeta necesita `position: relative` para que la etiqueta absoluta se coloque respecto a ella.

Con `overflow: hidden`, la etiqueta queda cortada porque sobresale de la tarjeta. Se puede solucionar quitando esa propiedad.

## Parte B
- visible: deja que el contenido sobresalga.
- hidden: corta el contenido.
- scroll: muestra barras de desplazamiento.
- auto: muestra las barras cuando hacen falta.

He dejado `auto` en el CSS.

## Parte C
- visibility: hidden oculta el elemento, pero mantiene su espacio.
- display: none oculta el elemento y elimina el espacio que ocupaba.
