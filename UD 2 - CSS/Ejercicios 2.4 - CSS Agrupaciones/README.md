- `block`: elementos en vertical.
- `inline-block`: elementos en fila.
- `flex`: organiza elementos en fila.

Las tarjetas saltaban de línea porque ocupaban 816px en total y no cabían. He reducido su tamaño y elegido `flex`.

## Preguntas

**1. Margin y padding:** padding es espacio interior y margin exterior.

**2. ¿Por qué saltaba la tercera tarjeta?** Porque no había espacio suficiente para las tres.

**3. ¿Qué ignoraba span?** Width y height, porque es un elemento en línea.

**4. ¿Qué hace display: none?** Oculta el elemento y elimina el espacio que ocupaba.
