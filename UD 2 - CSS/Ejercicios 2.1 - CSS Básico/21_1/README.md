# Ejercicio 1 - CSS

## ¿Cuál de las tres formas es más cómoda si tuviera que cambiar el color del título en 10 páginas?

La forma más cómoda sería utilizar CSS externo, porque todas las páginas pueden compartir el mismo archivo estilos.css. Solo tendría que modificar el color una vez en ese archivo y el cambio se aplicaría automáticamente a todas las páginas que lo tengan enlazado.

## ¿Por qué se desaconseja la primera forma (CSS en línea)?

Porque hay que repetir los estilos en cada elemento HTML. Esto hace que el código sea laargo, difícil de mantener, incoveniente de leer en un editor y complicado de modificar cuando una página tiene muchos elementos.
